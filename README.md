# GeoExplain
This is the supplemntary material of submission: "GeoExplain: Multimodal Reasoning based on Hierarchy of Visual Information in Street View". We provide the whole dataset and instructions on how to access it in this page. The repository structure is as below:

GeoExplain/<br>
├── readme.md<br>
├── GeoExplain_explanations.json<br>
├── GeoExplain_train_test_split.json<br>
├── A GeoExplain Example - Panoramas/<br>
│   ├── ...(images)<br>
├── GeoKnowledge_knowledge_text.json<br>
├── A GeoKnowledge Example - China/<br>
│   ├── ...(images)<br>
├── Results/<br>
│   ├── deepseekvl2_results.json<br>
│   ...<br>
│   ├── SightSense_results.json<br>
├── SightSense/<br>
│   ├── dataset.py<br>
│   ...<br>
│   ├── utils.py<br>

The whole GeoExplain (paronamas) can be accessed via link: https://drive.google.com/file/d/1eVWh9Tywohw-wz9VgNRr3JST42nhzmky/view?usp=sharing<br>
The whole GeoKnowledge can be accessed via link: https://drive.google.com/file/d/19A6tCIFUfW6YbAKY-bnEqFxpExGPsghi/view?usp=sharing

GeoExplain_explanations.json - provides ground truth explanations<br>
GeoExplain_train_test_split.json - provides train_test splits<br>
A GeoExplain Example - provides an example of panoramas in GeoExplain (full dataset can be accessed via link above)<br>
GeoKnowledge_knowledge_text.json - provides knowledge text<br>
A GeoKnowledge Example - provides an example of image set in GeoKnowledge (full knowledge set can be accessed via link above)<br>
Results - provides generated results by SightSense and baseline models<br>
SightSense - provides all code of SightSense
